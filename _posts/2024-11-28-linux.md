## Antes de tocar discos

Estos comandos son muy utiles para diagnosticar o ampliar almacenamiento, pero conviene ir con calma. Antes de cambiar LVM, particiones o ZFS, revisa `lsblk`, `pvs`, `vgs` y `lvs`, confirma el disco correcto y asegúrate de tener backup o snapshot. Un `zpool scrub` revisa integridad y puede meter bastante I/O, mejor lanzarlo en una ventana tranquila.

## LVM y discos

```bash
lsblk
pvs
vgs
lvs
vgchange -ay
lvextend -r -L +10G /dev/<VG>/<LV>
```

## ZFS

```bash
zpool status
zpool list
zfs list
zpool scrub <POOL>
```

## Journalctl

```bash
journalctl -xe
journalctl -u <SERVICIO> -f
journalctl --since "1 hour ago"
```
